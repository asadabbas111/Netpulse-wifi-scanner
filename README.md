## 🚀 Overview

**NetPulse** is a modern Windows desktop application built for **network monitoring, LAN device discovery, and Wi-Fi analysis**. It provides an intuitive graphical interface that allows users to inspect their local network, discover connected devices, analyze nearby Wi-Fi networks, and securely view Wi-Fi passwords **already saved on their own Windows computer**.

Designed with speed, simplicity, and a clean dark interface, NetPulse is an excellent project for cybersecurity students, IT professionals, and home network administrators.

---

## ✨ Key Features

🔍 **LAN Device Discovery**
- Detect all active devices connected to your local network
- View IP Address, MAC Address, Hostname, Vendor, Latency, and Device Role
- Export scan results to CSV

📶 **Nearby Wi-Fi Survey**
- Scan nearby wireless networks
- Display SSID, Signal Strength, Channel, Frequency Band, Security Type, and BSSID
- Easily identify the strongest nearby access points

🔐 **Saved Wi-Fi Password Viewer**
- Display passwords only for Wi-Fi networks previously saved on your Windows PC
- One-click password copy
- Administrator mode support for complete visibility

🎨 **Modern Desktop Interface**
- Built with CustomTkinter
- Responsive dark theme
- Fast and user-friendly experience

> ⚠️ **Security Notice**
>
> NetPulse only displays passwords for Wi-Fi networks that are **already saved on the current Windows computer**. It does **not** recover, crack, or bypass passwords for unknown wireless networks. Please use this software only on networks you own or are authorized to manage.
